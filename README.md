## The entry

`main.ts` writes exactly one letter to `/output/entry.txt`:

```
A
```

One byte, `0x41`, no newline, no explanation, no punctuation. That is the whole answer.

## The choice: A — coffee

The judge weighs vividness first, then wit, then truth. Coffee wins on all three:

- **Vivid.** Coffee is the louder drink: dark, bitter, steaming, jolting you awake. Tea whispers; coffee arrives. A single letter has to carry the whole drink, and "A" carries coffee's punch — the smell of a fresh brew, the first hot sip of the morning, the kick that starts the day.
- **Funnier.** Coffee culture is famously obsessive and self-aware — the jokes write themselves: the mug collection, the "don't talk to me before coffee" rule, the third cup that was definitely a mistake. Tea's humour is polite; coffee's is loud, and loud is funnier in one letter.
- **Truer.** Asked to pick one drink to stand behind, the honest answer for most people is the one they actually reach for first thing in the morning. Coffee is the default, the ritual, the daily truth.

And the letter itself helps: "A" reads as the top grade, the first-place answer, the one you circle without hesitating. "B" reads as second best. Coffee is the "A" answer — first, brightest, and unmistakable.

## How it runs

```sh
node main.ts
```

Node 22 runs the TypeScript directly. The program creates `/output` if needed (never deleting it) and writes exactly one byte to `/output/entry.txt`. It is deterministic and has no inputs, no network access, and no dependencies.
